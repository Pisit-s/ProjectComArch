Binary Lab — ห้องทดลองเลขฐานสองและ Floating-Point

เรียนรู้ว่าคอมพิวเตอร์แทนค่าและคำนวณตัวเลขด้วยเลขฐานสองและ Floating-Point อย่างไร ผ่านคำอธิบายทีละขั้น ตัวอย่างที่คำนวณได้จริง และเครื่องมือ Interactive ที่คุณทดลองเปลี่ยนบิตได้เอง

เริ่มเรียนบทที่ 1 ข้ามไปที่ IEEE 754

แนะนำให้เรียนตามลำดับ: จำนวนเต็มฐานสอง → เศษส่วนฐานสอง → IEEE 754 → การบวก/ลบ Floating-Point

บทเรียน

  1. บทที่ 1

    ระบบเลขฐานและจำนวนเต็มฐานสอง

    ค่าประจำหลักของเลขฐานสิบและฐานสอง น้ำหนักบิต และการแปลงจำนวนเต็ม 8 บิตเป็นเลขฐานสิบ

    เริ่มเรียน
  2. บทที่ 2

    เศษส่วนฐานสิบและเศษส่วนฐานสอง

    ค่าน้ำหนัก 2^-1 ถึง 2^-16 การแปลงเศษส่วนฐานสิบเป็นฐานสอง และความหมายของความคลาดเคลื่อน

    เริ่มเรียน
  3. บทที่ 3

    IEEE 754 Single Precision

    โครงสร้าง 1 + 8 + 23 บิต, Bias 127, การ Encode/Decode และข้อจำกัดของความแม่นยำ 32 บิต

    เริ่มเรียน
  4. บทที่ 4

    การบวกและการลบ Floating-Point

    ปรับ Exponent, บวก/ลบ Significand, Normalize, Rounding และผลกระทบต่อผลลัพธ์จริง

    เริ่มเรียน

สีที่ใช้ทั้งเว็บไซต์

เราใช้สีและ Label อย่างสม่ำเสมอเพื่อแยกส่วนของข้อมูล:

  • Sign เครื่องหมาย (1 บิต)
  • Exponent เลขชี้กำลัง (8 บิต)
  • Fraction เศษส่วนของ Significand (23 บิต)
