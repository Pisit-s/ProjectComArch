บทที่ 2: เศษส่วนฐานสิบและเศษส่วนฐานสอง

Learning Objectives

  • เข้าใจค่าประจำหลักของเศษส่วนฐานสิบ เช่น 10^-1, 10^-2
  • เข้าใจค่าน้ำหนักประจำหลักของเศษส่วนฐานสอง เช่น 2^-1, 2^-2
  • คำนวณค่าเลขฐานสิบจากเศษส่วนฐานสองได้
  • เข้าใจว่าเศษส่วนฐานสิบบางค่าไม่สามารถแทนด้วยบิตฐานสองจำนวนจำกัดได้อย่างแม่นยำ

แนวคิดหลัก: น้ำหนักของบิตเศษส่วน

ในระบบฐานสิบ ตำแหน่งหลังจุดมีน้ำหนักเป็น 10^-1, 10^-2, 10^-3, … เช่น 0.375 = 3×10^-1 + 7×10^-2 + 5×10^-3

ในระบบฐานสอง ตำแหน่งหลังจุดมีน้ำหนักเป็น 2^-1, 2^-2, 2^-3, … ได้แก่ 0.5, 0.25, 0.125, 0.0625, …

0.101₂ = 1×2^-1 + 0×2^-2 + 1×2^-3
        = 0.5 + 0 + 0.125 = 0.625₁₀

วิธีแปลงเศษส่วนฐานสิบเป็นฐานสอง: คูณด้วย 2 ซ้ำ ๆ

นำเศษส่วนคูณด้วย 2 เก็บ "ส่วนจำนวนเต็ม" เป็นบิต แล้วนำ "เศษส่วนที่เหลือ" ไปคูณต่อ ทำซ้ำจนเศษเป็น 0 หรือครบจำนวนบิต

0.375 × 2 = 0.75  → บิต 0, เศษ 0.75
0.75  × 2 = 1.5   → บิต 1, เศษ 0.5
0.5   × 2 = 1.0   → บิต 1, เศษ 0
ผลลัพธ์: 0.011₂  (แม่นยำ)

แต่ 0.1₁₀ ให้ผลเป็น 0.0001100110011…₂ ซ้ำไม่สิ้นสุด การเก็บบิตจำนวนจำกัดจึงได้เพียงค่าประมาณ (Approximation) และเกิด Absolute Error

    Interactive B: Decimal Fraction Converter

    ป้อนเศษส่วนฐานสิบ (ระหว่าง 0 ถึง 1) เลือกจำนวนบิต แล้วดูขั้นตอนการคูณด้วย 2

    ตัวอย่าง: 0.375, 0.625, 0.1

    สรุปท้ายบท

    • บิตเศษส่วนฐานสองมีน้ำหนัก 2^-1, 2^-2, 2^-3, …
    • แปลงเศษส่วนฐานสิบเป็นฐานสองด้วยการคูณ 2 ซ้ำ ๆ เก็บส่วนจำนวนเต็มเป็นบิต
    • เศษส่วนฐานสิบบางค่า (เช่น 0.1) มีรูปแบบฐานสองซ้ำไม่สิ้นสุด การเก็บบิตจำกัดจึงได้ค่าประมาณและเกิด Absolute Error
