บทที่ 1: ระบบเลขฐานและจำนวนเต็มฐานสอง

Learning Objectives

  • เข้าใจแนวคิดของระบบเลขฐานและค่าประจำหลัก (Place Value)
  • อธิบายความสัมพันธ์ระหว่างเลขฐานสิบ (Base 10) และเลขฐานสอง (Base 2)
  • แปลงจำนวนเต็มฐานสองแบบไม่มีเครื่องหมาย (Unsigned Binary Integer) เป็นเลขฐานสิบได้
  • อธิบายได้ว่าแต่ละบิตมีส่วนต่อค่ารวมอย่างไร

แนวคิดหลัก: ค่าประจำหลัก

ในระบบเลขฐานสิบ เลขแต่ละหลักมี "น้ำหนัก" ต่างกัน ตัวอย่างเช่นเลข 3 4 7 หมายถึง 

347 = 3×10² + 4×10¹ + 7×10⁰ = 300 + 40 + 7

ระบบเลขฐานสองใช้หลักการเดียวกัน แต่มีเพียงสองสัญลักษณ์คือ 0 และ 1 และใช้ฐาน 2:

1011₂ = 1×2³ + 0×2² + 1×2¹ + 1×2⁰ = 8 + 0 + 2 + 1 = 11₁₀

บิตที่มีค่า 0 ไม่มีส่วนเพิ่มในผลรวม ส่วนบิตที่มีค่า 1 จะเพิ่มค่าตามน้ำหนักประจำหลักของตำแหน่งนั้น

Unsigned 8-bit Integer

จำนวนเต็มฐานสองแบบไม่มีเครื่องหมายขนาด 8 บิต ใช้พื้นที่ 8 บิต มีน้ำหนักตั้งแต่ 2⁰ ถึง 2⁷ (คือ 1, 2, 4, 8, 16, 32, 64, 128) ทำให้มีช่วงค่า 0 ถึง 255

ตัวอย่างการแปลงทีละขั้น: 00001010₂

b7..b0 = 0 0 0 0 1 0 1 0
น้ำหนัก = 128 64 32 16 8 4 2 1
เปิดเฉพาะ b3 และ b1 → 8 + 2 = 10₁₀

ดังนั้น 00001010₂ = 10₁₀
