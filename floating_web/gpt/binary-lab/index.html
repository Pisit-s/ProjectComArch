CHAPTER 01 / FOUNDATION

ระบบเลขฐานและจำนวนเต็มฐานสอง

ทุกข้อมูลดิจิทัลเริ่มต้นจากบิต เรียนรู้ค่าประจำหลักและวิธีที่บิตแต่ละตัวสร้างจำนวนเต็ม

◎

เป้าหมายการเรียนรู้

เข้าใจค่าประจำหลัก • แปลง Binary เป็น Decimal • อธิบายช่วงค่าของ Unsigned 8-bit Integer ได้

01.1 · CORE CONCEPT

ค่าประจำหลักคืออะไร?

ระบบเลขฐานสิบ (Base 10) ใช้ตัวเลข 0–9 โดยแต่ละตำแหน่งมีน้ำหนักเป็นกำลังของ 10 เช่น 347 = 3×10² + 4×10¹ + 7×10⁰

หลักร้อย10²100
หลักสิบ10¹10
หลักหน่วย10⁰1
ตัวอย่างฐานสิบ347 = 3×100 + 4×10 + 7×1

ระบบเลขฐานสอง (Base 2) ใช้เพียง 0 และ 1 แต่ละตำแหน่งมีน้ำหนักเป็นกำลังของ 2 เช่น 1010₂ = 1×2³ + 0×2² + 1×2¹ + 0×2⁰ = 10₁₀

บิต b32³8
บิต b22²4
บิต b12¹2
บิต b02⁰1
01.2 · KEY IDEA

Unsigned 8-bit Integer

จำนวนเต็มแบบไม่มีเครื่องหมายใช้ทั้ง 8 บิตแทนค่าที่ไม่ติดลบ ตั้งแต่ 0 ถึง 2⁸−1 = 255

CHAPTER 02 / FRACTIONS

เศษส่วนฐานสิบและเศษส่วนฐานสอง

สำรวจน้ำหนักบิตหลังจุดฐาน และดูการแปลงเศษส่วนด้วยการคูณ 2 ซ้ำ ๆ

◎

เป้าหมายการเรียนรู้

คำนวณค่าจาก Binary Fraction • แปลงเศษส่วนฐานสิบ • อธิบาย Approximation และ Absolute Error ได้

02.1 · PLACE VALUE

น้ำหนักหลังจุดฐาน

หลังจุดทศนิยมของฐานสิบ น้ำหนักจะเป็น 10⁻¹ = 0.1, 10⁻² = 0.01 และ 10⁻³ = 0.001 ส่วนฐานสองใช้ 2⁻¹, 2⁻², 2⁻³ ตามลำดับ

บิต b12⁻¹0.5
บิต b22⁻²0.25
บิต b32⁻³0.125
บิต b42⁻⁴0.0625
ตัวอย่าง 0.101₂1×2⁻¹ + 0×2⁻² + 1×2⁻³ = 0.625₁₀

การแปลงจากฐานสิบใช้วิธีคูณเศษส่วนด้วย 2 ซ้ำ ๆ บิตถัดไปคือส่วนจำนวนเต็มของผลคูณ แล้วนำเศษส่วนที่เหลือไปทำขั้นต่อไป

02.2 · APPROXIMATION

ทำไม 0.1 ถึงไม่พอดี?

เศษส่วนบางค่า เช่น 0.1₁₀ มีรูปแบบฐานสองที่ซ้ำไม่สิ้นสุด คล้ายกับ 1/3 = 0.3333… ในฐานสิบ

แนวคิด0.1₁₀ ≈ 0.0001100110011…₂

เมื่อมีจำนวนบิตจำกัด เราต้องเก็บเพียงบางส่วน จึงเกิด Absolute Error หรือค่าสัมบูรณ์ของผลต่างระหว่างค่าเดิมกับค่าที่ประมาณได้

Approximation · ค่าประมาณ

การประมาณไม่จำเป็นต้องผิดพลาดมากเสมอไป แต่ต้องแยกค่าจริงทางคณิตศาสตร์ออกจากค่าที่จัดเก็บได้

CHAPTER 03 / FLOAT32

IEEE 754 Single Precision

จำนวนจริงในคอมพิวเตอร์ถูกเข้ารหัสเป็นบิต 32 บิตด้วย Sign, Exponent และ Fraction

◎

เป้าหมายการเรียนรู้

เข้าใจ Scientific Notation • อธิบาย Bias 127 • เข้ารหัสและถอดรหัส Float32 ได้

03.1 · SCIENTIFIC NOTATION

Normalize ก่อนจัดเก็บ

Scientific Notation ฐานสิบเขียน 1250 เป็น 1.25 × 10³ ส่วนเลขฐานสองแบบ Normalized เขียนเป็น 1.xxxxx₂ × 2ᵉ เช่น 5.75₁₀ = 101.11₂ = 1.0111₂ × 2²

Biased ExponentE = e + Bias = 2 + 127 = 129 = 10000001₂

สำหรับค่าปกติ (Normalized) เลข 1 ตัวแรกของ Significand ไม่ต้องเก็บซ้ำ เพราะเป็น 1 เสมอ จึงเรียกว่า Hidden Leading 1

03.2 · 32-BIT STRUCTURE

โครงสร้าง Binary32

SIGN1เครื่องหมาย
EXPONENT8เลขชี้กำลัง + Bias
FRACTION23ส่วนเศษของ significand
สูตรสำหรับ Normalized(−1)ˢ × 1.F × 2^(E−127)

เวอร์ชันนี้แสดงรายละเอียดพิเศษของ Subnormal, Infinity, NaN และ Signed Zero ผ่านผลการถอดรหัส แต่การไล่ขั้นตอน Normalize แบบละเอียดเน้นค่าปกติที่รองรับ

CHAPTER 04 / ARITHMETIC

การบวกและการลบ Floating-Point

เรียนรู้ว่าทำไมการบวกเลขแบบ Float32 จึงต้องจัดแนวเลขชี้กำลังก่อนคำนวณ

◎

เป้าหมายการเรียนรู้

แยกส่วนประกอบ • ปรับ Exponent • บวก/ลบ Significand • เข้าใจผลของ Rounding

04.1 · ALIGN EXPONENTS

ทำไมต้องปรับ Exponent?

ก่อนบวกหรือลบ Significand ต้องเขียนตัวเลขให้อยู่ในรูปที่มีเลขชี้กำลังเท่ากัน โดยเลื่อนจุดฐานของ significand ของค่าที่มี Exponent น้อยกว่า

ตัวอย่างแนวคิด1.0 × 2³ + 1.0 × 2¹
= 1.0 × 2³ + 0.01 × 2³

เมื่อ Exponent เท่ากัน จึงนำ significand มาบวกหรือลบตามเครื่องหมาย จากนั้น Normalize ผลลัพธ์และปัดให้พอดีกับความละเอียดที่มี

04.2 · ROUNDING

ค่าที่คาดหวังอาจต่างกัน

ตัวถูกดำเนินการแต่ละตัวถูกปัดเป็น Float32 ก่อนคำนวณ เครื่องมือจึงใช้ค่าที่เก็บได้จริง ไม่ใช่ค่าทศนิยมเดิมที่พิมพ์เข้ามา

ตัวอย่างfround(fround(0.1) + fround(0.2))
≈ 0.30000001192092896
แบบจำลองเพื่อการเรียนรู้

ขั้นตอนในหน้านี้แสดงแนวคิดหลักของการคำนวณ Floating-Point ไม่ใช่รายละเอียดวงจรภายในของ CPU ทุกสถาปัตยกรรม
