- ถ้าคำตอบต่าง ต้องแก้: `src/lib/site.ts`
- สถานะ: ตอบแล้ว — ใช้ Binary Lab

### Q2 [ไม่ด่วน] เครดิตผู้จัดทำใน footer

- สถานะ: ตอบแล้ว — ตามรายชื่อใน PLAN.md 7.1

### Q3 [ยืนยันค่าเริ่มต้น] ความละเอียดของกรณีพิเศษ

- ค่าที่สมมติไว้ตอนนี้: ตามนั้น
- ถ้าคำตอบต่าง ต้องแก้: `src/content/step-text.ts`, หน้าบทที่ 3–4
- สถานะ: รอคำตอบ

### Q7 [ไม่ด่วน] Half / Double ใน Lab
- คำถาม: อยากได้ Half (16 บิต) / Double (64 บิต) ใน Lab ไหม
- ค่าที่สมมติไว้ตอนนี้: ยังไม่ทำ (engine รองรับ binary16/binary64 แล้วและมี test แต่ UI ยังเป็น 32 บิต) — ถ้าต้องการ ต้องส่ง format ผ่าน FpSimulator, Register, StepView และ ResultCompare
- ถ้าคำตอบต่าง ต้องแก้: `src/components/tools/*`, `src/components/viz/*`, `src/lib/url-state.ts`
